# BlueFish AI · 阿鳍 AI 情报局 — Feedback

Official feedback and corrections for [BlueFish AI](https://bluedafeiyu.win/). Website source remains in its separate private repository.

Use Issues for bugs, source corrections and copyright/takedown requests. Chinese, Japanese, English, Korean, French, German, Italian and Spanish are welcome.

Issues are public and require a GitHub account. Submit only the affected page, a description and public source/rights links. Do not post API keys, passwords, private conversations, identity documents, payment details or private contact information. If the matter requires private evidence, first request an appropriate private follow-up without attaching it publicly.

Copyright claims are reviewed by the site owner. Potentially unauthorized disputed content should be suspended during verification; attribution alone does not grant a copying license. Findings and actions are recorded in the website operations rights ledger. No response deadline or legal determination is promised.
